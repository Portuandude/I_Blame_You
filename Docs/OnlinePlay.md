# 컴퓨터 두 대로 2인 플레이 (온라인)

2026-11-16 사람 결정: 기획 의도는 **두 사람이 각자 컴퓨터로** 같이 하는 것이고, 최종 배포는 **스팀**이다.
2026-11-17 사람 결정: 데디케이티드 서버가 아니라 **호스트 방식**으로 게임 안에 온라인을 만든다.

## 지금 되는 것 (게임 안 온라인, 호스트 방식)

시작 화면 아래 **"온라인 2인 (호스트 하기 / 참가하기)"** 버튼.

- **호스트 (P1, 이동·순간이동, 키보드)**: "호스트 하기 (방 열기)" → 창에 보이는 주소를 친구에게 알려 준다 → "닫고 게임 시작하기" 뒤 평소처럼 시작. 친구는 판 도중에도 들어올 수 있다.
  친구가 들어오면 P2 입력은 친구 것만 받는다 (호스트 마우스로는 공격이 안 나간다). 호스트 화면에는 친구 커서 자리가 주황 십자로 보인다.
  친구가 없을 때는 지금처럼 한 컴퓨터로 둘 다 할 수 있다.
- **친구 (P2, 공격, 마우스)**: 주소 칸에 호스트 주소 → "참가하기". 내 화면은 호스트 화면을 그대로 보여 주고, 내 마우스·숫자줄·Space·Esc가 P2 입력으로 간다. **F10**: 연결 끊기.
- 두 사람은 **같은 빌드**여야 한다 (다르면 접속할 때 거절된다). `Tools > I Blame You > Windows 빌드 만들기`로 만든 폴더를 친구에게 그대로 준다.
- **지연 표시·끊김**: 두 화면 오른쪽 아래에 왕복 지연(예: "지연 45ms", 80ms 아래 초록·150ms 아래 노랑·그 위 빨강)이 보인다. 상대에게서 10초 동안 아무것도 오지 않으면 연결을 끊는다 (친구 컴퓨터가 꺼지거나 인터넷이 끊겨도 호스트가 자리를 비워 친구가 바로 다시 들어올 수 있다).
- **판 도중 친구가 끊기면** 호스트 게임이 일시정지 메뉴로 멈추고 위에 안내가 뜬다. 친구가 다시 참가하면 "다시 들어왔어요!"로 바뀌고, 계속하기를 누르면 이어 한다. 기다리지 않고 계속하기를 누르면 혼자(호스트 마우스가 P2) 이어 한다.
- **화면 비율을 같게** (둘 다 16:9 창 또는 전체 화면). 친구 마우스 자리는 화면 비율(0~1)로 보내기 때문.

### 인터넷 너머 친구와 하기

지금 연결은 **직접 IP(TCP, 기본 포트 27777)** 라서, 다음 중 하나가 필요하다.

1. **같은 집 네트워크**: 호스트 창에 보이는 `192.168.x.x` 주소를 쓴다.
2. **가상 LAN (추천)**: 두 사람 모두 Radmin VPN, ZeroTier, Tailscale 같은 무료 프로그램으로 같은 네트워크에 들어가고, 그 프로그램이 보여 주는 호스트 주소를 쓴다. 공유기 설정이 필요 없다.
3. **포트 열기**: 호스트 공유기에서 TCP 27777을 호스트 컴퓨터로 열고, 친구는 호스트의 공인 IP를 쓴다.

처음 방을 열 때 Windows 방화벽이 물으면 "허용"을 누른다.

**스팀 출시 때**: 스팀 친구 초대 + 스팀 중계(Steam Networking Sockets)로 바꾼다. 포트·주소 없이 초대만으로 들어온다. 전송 부분(`Net/Core/TcpTransport`)만 `ITransport` 모양으로 하나 더 만들면 나머지는 그대로 쓴다.

## 어떻게 동작하나 (만드는 사람용)

이 게임은 두 사람이 **한 몸, 한 화면**을 나눠 조작한다. 그래서 친구 컴퓨터가 게임을 따로 돌리지 않는다.

- **호스트가 게임 전체를 돌린다.** 적·마법·맵·저장 모두 호스트에만 있다. 판정이 어긋날 일이 없다.
- **친구 → 호스트**: 매 프레임 P2 입력 (`Net/Core/P2InputState`): 마우스 자리(화면 비율), 버튼·숫자줄 "누른 횟수"(짧게 톡 누른 것도 놓치지 않게), 휠 합.
  호스트의 `P2Input`이 이것을 Unity Input과 같은 모양으로 돌려준다. `RoleInput`의 B(공격) 입력은 모두 `P2Input`을 거친다.
  온라인이면 `GameSession.SharedKeyboard`가 false라 P1 키보드를 막지 않는다.
- **호스트 → 친구**: 매 프레임 끝에 (`NetHostStreamer`)
  - **그림 조각**: 씬의 SpriteRenderer·LineRenderer·TrailRenderer·TextMesh 중 **바뀐 것만** (자리·크기·회전·색·정렬·번쩍임) + 사라진 번호 + 카메라 (`Net/View/NetWorld`). 이 게임은 파티클·타일맵 없이 이 넷으로만 그린다. 새 종류를 쓰면 여기에 더한다.
  - **그림 파일**: 처음 쓰이는 텍스처·스프라이트만 PNG로 한 번 (`Net/View/NetAssets`). 코드로 만든 그림이 많아서 친구가 스스로 찾을 수 없기 때문.
  - **HUD**: IMGUI 그리기 명령 (`Net/View/HudRecorder`). OnGUI 파일 맨 위의 `using GUI = IBlameYou.Net.NetGUI;` 별칭이 GUI.Label 등을 평소처럼 그리면서 기록한다. **새 OnGUI 파일에도 이 줄을 꼭 넣는다** (없으면 친구 화면에 그 HUD가 안 보인다). `style.Draw` 대신 `GUI.StyleDraw`.
  - **소리**: 이름으로 (`NetAudio`, `GameAudio`가 낼 때마다 적는다).
  - **Ping**: 1초마다 호스트 시각 + 잰 지연. 친구는 그 시각을 Pong으로 돌려주고, 호스트가 왕복 시간을 잰다 (`Net/Core/NetPing`). 10초 무응답이면 호스트는 `ITransport.DropPeer`, 친구는 연결 끊기.
  - 1KB 넘는 메시지는 deflate로 줄인다. 보낼 것이 1.5MB 넘게 밀리면 새 그림을 잠시 건너뛴다.
- 친구 컴퓨터(`NetClientView`)는 받은 대로 카메라·조각을 놓고 HUD를 다시 그린다. 친구 창 크기에 맞춰 HUD를 늘이거나 줄인다.

### 알려진 한계

- 친구 쪽 화면은 왕복 지연만큼 늦다 (같은 나라면 보통 0.03~0.08초). 커서 옆 표시(스킬 이름표·다이얼)도 그만큼 늦게 따라온다.
- **공격 마법**: 친구는 자기 마우스로 마법진을 그린다 (`RoleInput.Circle*`가 `P2Input`을 읽는다, 2026-11-19 #117 합치기). 개발자 모드 숫자 즉시 발동도 된다.
- 메뉴(도시·상점·유물 고르기 등)는 호스트가 조작한다. 친구는 보기만.
- 시작 화면 기록 목록·아카데미 목록처럼 GUILayout 스크롤 칸 안은 친구 화면에 그리지 않는다.

## 다른 방법 (예전 정리)

| 방법 | 비용 | 메모 |
|---|---|---|
| Parsec 화면 공유 | 무료 | 게임 코드 없이 바로. 호스트는 마우스를 만지지 말 것 |
| Steam Remote Play Together | Steamworks 등록 100달러 | 출시 후 친구가 게임 없이 참여. 위 게임 안 온라인과 같이 둘 수 있다 |
| 데디케이티드 서버 | 매달 서버 요금 | 2026-11-17 하지 않기로 함: 둘 다 지연이 생기고(P1 이동까지), 협동 2인이라 공정성·핵 걱정이 거의 없다 |

## 1단계 시험 (Parsec, 계속 쓸 수 있음)

1. 호스트: `Tools > I Blame You > Windows 빌드 만들기` → `Builds/Windows/IBlameYou.exe`.
2. 두 사람 모두 [parsec.app](https://parsec.app)에서 Parsec 설치, 호스트가 친구를 초대하고 키보드·마우스 권한을 켠다.
3. 호스트 = P1 키보드만, 친구 = P2 마우스.
