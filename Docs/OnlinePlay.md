# 컴퓨터 두 대로 2인 플레이 (온라인 계획)

2026-11-16 사람 결정: 기획 의도는 **두 사람이 각자 컴퓨터로** 같이 하는 것이고, 최종 배포는 **스팀**이다. 이 문서는 그 기준으로 지금 당장 시험하는 길과 출시 때의 길을 정리한다.

## 결론

이 게임은 두 사람이 **한 몸, 한 화면**을 나눠 조작한다 (P1 = 이동·순간이동, P2 = 공격·마법). 두 사람이 서로 다른 곳을 볼 일이 없으므로, 호스트 컴퓨터에서 게임을 돌리고 친구는 그 화면을 받아 자기 마우스·키보드로 P2를 조작하는 **화면 공유 방식**이 잘 맞는다. 게임 코드는 거의 그대로 쓴다.

| 단계 | 언제 | 방법 | 비용 | 게임 코드 |
|---|---|---|---|---|
| 1 | 지금 (친구 베타) | Parsec으로 호스트 화면 공유 | 무료 | Windows 빌드 메뉴만 추가 (이 PR) |
| 2 | 스팀 출시 | Steam Remote Play Together | Steamworks 등록비 100달러 (매출로 회수) | 없음 (스팀이 처리) |
| 3 | 필요할 때만 | 진짜 네트워크 코드 (각자 컴퓨터에서 게임 실행) | 무료 (스팀 중계) | 큰 작업, 수 주 |

## 1단계: 지금 친구와 시험하기 (Parsec)

1. 호스트(P1): Unity에서 **Tools > I Blame You > Windows 빌드 만들기** → 끝나면 `Builds/Windows/IBlameYou.exe` 폴더가 열린다. (에디터 Play로 해도 되지만 빌드가 가볍고 전체 화면이 깔끔하다.)
2. 두 사람 모두 [parsec.app](https://parsec.app)에서 무료 계정을 만들고 Parsec을 설치한다.
3. 호스트가 Parsec에서 친구를 추가하거나 **Share** 링크를 보내고, 친구가 접속한다.
4. 친구가 들어오면 호스트가 그 친구에게 **키보드·마우스 권한**을 켠다.
5. 호스트가 게임을 켜고 화면 설정에서 **전체 화면 1280×720 또는 1920×1080**으로 맞춘다 (화면이 작을수록 친구 쪽 지연이 줄어든다).

역할:
- **호스트 = P1**: 키보드만 쓴다. **마우스는 만지지 않는다** (두 사람의 마우스가 같은 커서를 움직인다).
- **친구 = P2**: 마우스로 조준·평타·휠·우클릭 다이얼·마법진 그리기. 영창 타이핑은 친구 키보드로 친다 (영창 중에는 지금처럼 P1 키가 잠긴다).
- 스토리 건너뛰기: P1 Space + P2 마우스 왼쪽을 같이 꾹.

참고: Parsec은 호스트 쪽 그래픽카드의 하드웨어 인코딩이 필요하다 (요즘 NVIDIA·AMD·Intel 내장 그래픽이면 된다). 인터넷 너머여도 포트 포워딩은 필요 없다.

시험하면서 볼 것 (`Docs/PLAYTEST_AND_PROGRESS.md`에 적기):
- 친구 쪽 지연이 조준·마법진 그리기에 거슬리는지 (이게 3단계가 필요한지 가르는 기준)
- 두 사람의 입력이 섞여서 생기는 문제가 있는지

## 2단계: 스팀 출시 (Remote Play Together)

- Steamworks에 개발자 등록하고 앱을 만든다 (앱 하나에 100달러, 매출이 1,000달러를 넘으면 돌려받는다).
- 스팀에 올라간 게임은 **Remote Play Together**가 자동으로 된다: 호스트가 스팀 친구를 초대하면 친구는 **게임을 사지 않아도** 들어와서 마우스·키보드로 같이 한다. 스팀이 중계하므로 포트 포워딩도 필요 없다.
- 스팀 상점 페이지에 "Remote Play Together", "온라인 협동" 태그를 단다.
- 출시 전 베타는 **Steam Playtest** (같은 앱에 딸린 무료 시험판)로 친구·지원자를 받을 수 있다.
- 업로드: 1단계의 Windows 빌드 폴더를 SteamPipe로 올린다. 업적·스팀 클라우드 저장 등이 필요해지면 그때 Steamworks.NET을 붙인다.

## 3단계: 진짜 네트워크 코드 (필요할 때만)

각자 컴퓨터에서 게임이 돌고 입력과 상태만 주고받는 방식이다. 친구 쪽 지연이 줄고 화면도 원래 화질이지만, 지금 게임(스크립트 약 240개, 3만 8천 줄)은 한 컴퓨터 기준으로 짜여 있어서 적·투사체·맵·보스·UI를 모두 동기화하도록 고쳐야 한다. 수 주짜리 작업이고 그동안 다른 기능 개발이 밀린다.

하게 되면:
- 엔진 쪽: Unity **Netcode for GameObjects**, 호스트가 판을 돌리는 구조 (호스트 = P1 몸, 클라이언트 = P2 입력).
- 연결: 스팀 친구 초대 + **Steam Networking Sockets** (스팀 중계라 무료, 포트 포워딩 없음). 스팀 앱 ID가 생기기 전 시험은 스팀 공용 시험 앱 ID 480으로 한다.
- 시작점: P2 입력은 이미 `Player/Input/RoleInput`의 "플레이어 B" 부분에 모여 있다. 이 부분을 "로컬 마우스에서 읽기"와 "네트워크로 받은 입력 읽기" 두 가지로 나누는 것이 첫 단계다.

언제 하나: 1단계 시험에서 지연이 게임을 망칠 정도라고 판단되면. 그렇지 않으면 출시는 2단계로 충분하다.
