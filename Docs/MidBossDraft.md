# 스테이지 1 중간보스 기획 초안

> 2026-11-09 자동 개발 실행에서 작성한 **초안**. 구현은 사람이 후보를 고른 뒤 진행한다. 수치는 모두 가안이며 스탯 문서(`StatTable`) 기준에 맞춰 잡았다.

## 위치와 역할

- 스테이지 1은 약 30분, 정예 전투가 진행도 40%/72%에 있고 마지막이 보스 슬라임 킹(체력 1200)이다.
- 중간보스는 **진행도 약 55%**, 두 정예 전투 사이에 한 번. 전용 청크 `MidBoss`(전투 구역과 같은 잠금 구조, 보상 구슬 큼: 체력 50%·마나 100%).
- 목표: 슬라임 킹 전에 **"패턴을 읽고 A/B가 역할을 나누는"** 연습. 체력은 보스의 1/3 수준(350~450), 패턴 3~4개.
- 기존 시스템 재사용: `EnemyController`(체력·경직·사망), `ArenaZone`(잠금), 보스 체력바(`BossEvents`), 상태이상(`StatusEffects`).

## 후보 A: 고블린 주술사 (원거리·속성 퍼즐형)

- 체력 380 · 방어 15 · 마나 120(초당 6) · 속성 저항: 지금 들고 있는 **속성 보주와 같은 속성 100%, 반대 속성 -30%**.
- 패턴
  1. **보주 교체** (10초마다): 불/물/바람 보주 중 하나를 들고 몸 색이 바뀐다. 그 속성 마법은 통하지 않는다 → B가 영창을 바꿔야 한다.
  2. **속성탄 3연사**: 보주 속성 투사체. A의 같은 속성 방어막이면 완전 차단.
  3. **소환진** (마나 60): 고블린 2기. 소환진을 먼저 끊으려면 땅 가시.
  4. **순간이동**: 체력 50% 이하, 구역 반대편으로.
- A/B 협력 포인트: A는 보주 색을 보고 방어막 속성을 맞추고, B는 약점 속성을 친다. 봉인문 퍼즐(속성 맞히기)의 전투판.
- 필요 아트: 주술사 4동작, 보주 3색 (Tools/ArtGen 고블린 생성기 확장으로 가능).

## 후보 B: 바위 골렘 (근접·지형형)

- 체력 450 · 방어 40(평타가 잘 안 박힘) · 기력 120.
- 패턴
  1. **내려치기**: 앞 3칸 충격파 (점프로 피함).
  2. **바위 던지기**: 포물선, 떨어진 바위는 5초 동안 발판이 된다.
  3. **웅크리기** (체력 30%마다): 6초 동안 방어 +60, 대신 등의 핵이 드러나 **물 속성 마법**에 2배 피해.
  4. **지진**: 바닥 전체 피해 → 바위 발판 위로 피해야 한다.
- A/B 협력 포인트: A가 바위 발판을 타고 지진을 피하고, B가 웅크린 틈에 물 마법. 컨트롤 퍼즐(움직이는 발판) 청크의 전투판.
- 필요 아트: 골렘 4동작, 바위, 충격파 이펙트.

## 후보 C: 쌍둥이 슬라임 기사 (2체 동시형)

- 체력 각 200 · 한쪽이 쓰러지면 남은 쪽이 광폭화(`EnrageAbility` 재사용).
- 패턴: 왼쪽은 불 속성 돌진, 오른쪽은 물 속성 방패. 불 기사는 물 마법, 물 기사는 바람 마법에 약하다.
- 둘이 붙어 있으면 **화상+젖음 상쇄**(기존 규칙) 때문에 속성 공격이 꼬인다 → 떨어뜨려 놓고 하나씩.
- A/B 협력 포인트: A가 순간이동으로 둘 사이를 갈라놓고, B가 각자의 약점을 친다.
- 필요 아트: 기존 슬라임 회색판(`Resources/Enemies/SlimeGray`)에 기사 투구만 추가 → **가장 적은 아트로 가능**.

## 추천

- **C(쌍둥이 슬라임 기사)** 를 먼저: 기존 슬라임 아트·광폭화·상태이상 상쇄 규칙을 재사용해 가장 빨리 만들 수 있고, 슬라임 킹(분열) 전 예고편 역할도 한다.
- A는 봉인문과 주제가 이어져 좋지만 보주 교체·속성 저항 변경이 새 시스템이라 C 다음.

- [ ] 위치(진행도 55%) 확정
