# 런 사이 도시 설계 (2026-11-14 자동 실행 초안)

> 사람 결정 (2026-11-14): 판 사이에 **도시**를 허브로 둔다. 도시에서 **영구 능력치**와 **새 마법**을 산다.
> 큰 줄기 순서 ① 퍼즐 방(구현함) → **② 런 사이 도시** → ③ 숲. 이 문서는 ②의 설계다. 사람이 고를 것은 맨 끝 "정할 것".
> 이야기·이름은 [Story.md](Story.md) "마법 도시" 초안(클라리온, 수정 탑, 아카데미, 마음 가루)을 따른다. 예전 메타 진행 초안은 [MetaProgressionDraft.md](MetaProgressionDraft.md).

## 1. 지금 상태 (코드)

- 시작 화면(`Core/StartMenu.cs`, IMGUI)에서 바로 판이 시작되고, 판이 끝나면 결과 창 → 시작 화면.
- 판이 끝나면 남는 것: 설정, 최고 기록, 유물 도감 (`Core/SaveData.cs`, PlayerPrefs). **판 사이 성장은 없다.**
- 판 안의 돈은 골드(`RunGold`/`RunStats.Gold`)뿐이고 다음 판으로 넘어가지 않는다 (사람 결정: 골드는 그 판에서만).
- 마법: B 영창 4속성(불 화염구·물 물의 창·바람 돌풍·땅 바위 가시) + 평타 마력탄 (`Player/Skills/SpellBook`). A 방어막 4속성.

## 2. 흐름

```
 시작 화면 ──(시작)──▶ 도시 광장 ──(성문)──▶ 스테이지 (판)
                        ▲                         │
                        └──(쓰러짐·클리어: 광장에서 깨어남)──┘
```

- **도시는 걸어 다니는 한 화면 방**이다 (마을 방과 같은 평평한 지형 + 건물 그림). 적·함정 없음. 판과 같은 조작(A 이동, B 마법)으로 움직이고, 건물 앞에서 위(W)를 누르면 창이 열린다 (마을 식당·상점과 같은 방식, `SkillHUD.Village`).
- 건물 셋:
  1. **수정 탑** (가운데, 금이 간 큰 수정) — 마음 가루를 바쳐 **영구 능력치**.
  2. **아카데미** (왼쪽) — 마음 가루를 내고 **새 마법**을 배운다.
  3. **성문** (오른쪽 끝) — 지나가면 스테이지로. 스테이지를 깨면 다음 스테이지 성문이 열린다 (숲은 ③ 뒤).
- 처음 실행 때만 짧은 대사 (탑지기·선생님). 그다음은 한마디. 프롤로그 그림은 나중 (Story.md 연출 목록).
- 시작 화면의 "시작"은 도시로 간다. 기능 테스트는 지금처럼 바로 테스트 맵.

## 3. 화폐: 마음 가루

| 얻는 곳 | 양 (가안) |
| --- | --- |
| 적 처치 | 쫄몹 1 · 정예 5 · 중간보스 15 · 보스 40 |
| 퍼즐 방 풀기 | 5 |
| 스테이지 클리어 | +20 |

- **쓰러져도 모두 남는다** (Story.md: 영혼에 달라붙는 가루). 대신 양을 작게 잡아 한 판에 평균 40~70.
- 골드와 다르다: 골드는 판 안(마을 식당·상점), 가루는 판 밖(도시). 결과 창에 "마음 가루 +N" 한 줄.
- 저장: `SaveData`에 `HeartDust`(정수) 키 하나 + 산 것 키들. 개발자 모드 기록은 지금처럼 따로 저장.

## 4. 수정 탑: 영구 능력치

"강해지기보다 넓어지기"(메타 초안 원칙)에 맞춰 단계와 폭을 작게 둔다. 각 5단계, 값은 단계마다 같은 만큼.

| 항목 | 한 단계 | 최대 (5단계) | 가루 (1→5단계) |
| --- | --- | --- | --- |
| 최대 체력 | +4 | +20 (기본 100) | 20 · 35 · 55 · 80 · 110 |
| 최대 마나 | +4 | +20 (기본 100) | 20 · 35 · 55 · 80 · 110 |
| 마나 재생 | +3% | +15% | 25 · 40 · 60 · 85 · 115 |
| 방어막 지속 | +0.1초 | +0.5초 (기본 3초) | 25 · 40 · 60 · 85 · 115 |

- 다 사려면 약 1,300 가루 ≈ 20~30판. 처음 몇 판은 한 판마다 하나씩 산다.
- 탑에 바칠수록 수정의 금이 하나씩 메워지는 그림 (진행이 눈에 보이게).

## 5. 아카데미: 새 마법

새 영창 마법을 배우면 **B의 영창 목록에 그 마법이 하나 더 생긴다** (기존 4속성은 그대로). 각 마법은 한 번 사면 끝.

| 마법 | 속성 | 하는 일 | 가루 |
| --- | --- | --- | --- |
| 불꽃 장막 | 불 | 앞에 2초 동안 불벽 (지나가는 적 화상) | 60 |
| 물방울 회복 | 물 | 마나 30을 써서 체력 8 회복 (A·B 공용 체력이라 협동 선택) | 80 |
| 회오리 | 바람 | 주변 적을 끌어모은다 (넓은 판에서 몰아잡기) | 70 |
| 돌 방패 | 땅 | A 앞에 3초 돌벽 (투사체 막음) — B가 A를 지키는 마법 | 70 |

- 영창 문장은 기존처럼 짧은 문장 (예: "불꽃이여, 벽이 되어라!"). 영창 창에서 같은 속성 마법이 둘이면 Tab으로 고른다 (메타 초안 후보 C의 방식).
- 그림·효과음은 기존 속성 이펙트를 다시 쓴다 (불벽은 불기둥 그림, 돌벽은 바위 가시 그림).

## 6. 구현 단계

1. **가루와 저장**: `RunStats.HeartDust` 집계(처치·퍼즐·클리어) + 결과 창 줄 + `SaveData` 누적. 순수 C# 규칙은 `Chunks`처럼 테스트 가능한 정적 클래스(`HeartDustRule`).
2. **도시 방**: 시작 → 도시 장면(한 화면 방, 건물 셋, 성문). 성문 → 지금의 판 시작.
3. **수정 탑 창**: 4항목 × 5단계 사기, 판 시작 때 능력치에 더함 (`StatTable`이 아니라 플레이어 생성 뒤 덧붙임).
4. **아카데미 창 + 새 마법 1개** (돌 방패부터: A/B 협동이 가장 분명), 그다음 나머지 셋.
5. 대사·탑 금 메우기 연출.

## 7. 정할 것 (사람)

1. 가루 양: 한 판 평균 40~70, 전부 다 사는 데 20~30판 — 이 속도가 괜찮은지.
2. 영구 능력치 4항목(체력·마나·마나 재생·방어막 지속)이 맞는지, 이동 속도·대시 같은 다른 것을 넣을지.
3. 새 마법 4개 후보 중 무엇부터 (기본안: 돌 방패 → 불꽃 장막 → 회오리 → 물방울 회복).
4. 도시를 걸어 다니는 방으로 할지(기본안), 시작 화면처럼 메뉴 창만으로 할지 (메뉴면 훨씬 빠르다).
5. 시작 화면의 "시작"이 바로 도시로 갈지(기본안), 시작 화면에 "도시" 버튼을 따로 둘지.
