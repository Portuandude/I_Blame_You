# I Blame You! — 게임 기획 문서

> 작성 중인 문서. 섹션은 채워지는 대로 갱신한다. 마지막 갱신: 2026-11-09 (청크식 스테이지, 2인 A/B 조작, 마나 스킬, 적/정예/보스, 특성 트리, 상태이상, 전투 구역 보상, 설정·최고 기록 저장 반영).
> 조작키·수치·폴더 구조의 자세한 내용은 [README.md](../README.md)가 기준이다. 이 문서는 기획 의도와 구현 현황을 정리한다.

## 1. 게임 개요

- 로그라인: 마법사 한 명을 두 사람이 나눠 조작한다. A는 몸(이동·방어), B는 마법(공격). 마나는 하나뿐이라 실패하면 서로 탓하게 된다 — "I Blame You!"
- 장르: 2D 횡스크롤 액션 로그라이크. 시드로 매번 새로 만들어지는 청크식 스테이지 + 패턴 파훼형 전투 + 함정 지형.
- 목표 플레이 시간: 스테이지 하나 15분 안팎 (보스 포함, 2026-11-10 사람 결정으로 30분 → 15분).

## 2. 게임 시스템 디자인

### 게임 진행 방식

- 로그라이크
  - 스토리형 (로직, 퍼즐) — 미구현
  - 패턴 파훼형 (EX. 컵헤드, 다크소울류) — 보스 슬라임 킹으로 구현
- 횡스크롤 2D 플랫포머 (확정)
- 쫄몹 + 정예몹 + 보스 + 맵퍼즐 (스킬 퍼즐: 속성 봉인문, 컨트롤 퍼즐: 움직이는 발판 — 둘 다 구현됨)
- 한 판(런): 시작 화면 → 스테이지 1 (시드 생성) → 보스 돌파 → 출구 진입 시 클리어. 쓰러지면 게임오버 후 새 맵으로 다시 시작

### 2인 분담 조작 (구현됨)

한 캐릭터를 플레이어 A와 B가 나눠 조작하고, 마나를 같이 쓴다.

| 역할 | 맡는 것 | 스킬 입력 방식 (일반 모드) |
| --- | --- | --- |
| A | 이동, 점프, 달리기, 대쉬, 순간이동, 속성 방어막 | 방어막: 화면에 뜬 W/A/S/D 순서를 입력 (입력 중 캐릭터 정지, 틀리면 마나만 소모) |
| B | 평타, 속성 공격 스킬 | 공격 스킬: 영창문을 그대로 타이핑 후 Enter (오타면 마나만 소모) |

- **개발자 모드** (시작 화면에서 선택, 기본 켜짐): 한 사람이 A/B를 동시에 조작하고 미니게임 대신 숫자키로 즉시 발동. 치트 F1~F4.
- **기능 테스트 모드** (시작 화면 "기능 테스트 시작", 2026-11-12 플레이테스트 피드백): 적 없는 시험용 외길(빈 방·협동 봉인문·이중 스위치 발판)에서 몬스터 소환(F7/F8), 유물 장착·해제(F9), 구역 이동(F10), 미니게임 켜고 끄기(F5), 결과 창 "누구 탓?" 도장(F11), 장비 끼기·빼기(F12)를 바로 시험한다. 기록은 남지 않는다. 일반 판은 "플레이 테스트 시작".
- 지금은 한 키보드를 같이 쓰므로 B가 타이핑하는 동안 A의 키 입력은 막힌다. 온라인(데디케이티드 서버)은 미구현.
- **마나 탓하기**: 마나가 모자라 스킬이 실패하면, 최근에 상대가 더 많이 썼을 때 HUD 피드에 상대 탓을 한 줄 덧붙인다. 클리어 화면에 A/B가 날린 마나를 보여준다.

### 속성과 스킬 (구현됨)

- 속성 5종: 불 / 물 / 바람 / 땅 / 무. 피해는 비율식 `공격 × 100 / (100 + 방어)` (`DamageCalculator`).
- A: 순간이동(마나 20), 속성 방어막 5종.
  - 순간이동은 상/하/좌/우 4방향 (대각선 없음, 같은 세기면 세로 우선). 벽 점프는 넣지 않고 이것이 세로 이동 수단이다 (2026-11-09 결정). 입력은 W/A/S/D + Enter (2026-11-12 방향키에서 바꿈). 아래 순간이동은 발판 역할 오브젝트(한쪽·움직이는·스위치·무너지는 발판)를 모두 뚫는다.
    좌/우/위는 땅·발판 앞에서 멈춘다. 아래는 발판을 뚫고 내려가지만 땅은 뚫지 않고, 도착 지점 발 밑 2.5칸(점프 높이) 안에 디딜 곳이 없거나 낙사 높이 아래로 떨어지는 경로면 거리를 줄이며, 0.5칸 이상 갈 안전한 곳이 없으면 발동하지 않는다 (마나 소모 없음, 빨간 실패 표시). 규칙은 `Player/Skills/Rules/TeleportRules.cs` (EditMode 테스트).
- B: 평타(마우스 방향), 속성 공격 스킬 5종 (`SpellBook`).

### 상태이상 (구현됨)

| 디버프 | 원인 | 효과 |
| --- | --- | --- |
| 화상 | 불 | 중첩. 1초마다 중첩 수 × (공격자 불 속성 데미지 / 10) 고정 피해, 5초 |
| 젖음 | 물 | 3초 동안 이동속도 40% 감소 (화상과 서로 지움) |
| 경직 | 땅 | 1초 동안 이동/공격 정지 |

- 확률: `7.5 / 디버프 저항도` (최대 100%). 머리 위 `StatusIconBar`에 아이콘 표시. 플레이어도 화염 분출구로 화상을 입는다.

### 성장: 레벨업 특성 (구현됨)

- 적 처치 경험치로 레벨업, 레벨마다 특성 포인트 1 (A/B 공용 주머니). 다음 레벨까지 `60 + 25 × (레벨 - 1)`.
- Tab 특성 창(게임 정지): 분노(B 공격) / 신속(A 이동) / 인내(A 방어) / 신비(마나) / 생명(체력) 다섯 갈래, 5·10·20포인트 보너스. 표는 README 참고.

### 게임 인터페이스 (UI/UX)

테스트 단계라 모든 UI는 IMGUI로 그린다. 정식 UI 아트로 가는 중: 왼쪽 위 체력·마나는 하트·별 아이콘 + 둥근 캡슐 바 + 빛 테두리로 그리고, 줄어든 부분은 흰 잔상으로 0.45초 남았다가 따라 내려간다 (체력 30% 이하면 하트가 두근거림).

- 캐릭터 머리 위 HP/마나/기력 바 (`StatusBarsUI`), 상태이상 아이콘 (`StatusIconBar`)
- 적 머리 위 체력 바 (`EnemyHealthBar`): 맞으면 3초 보였다가 사라짐. 보스는 화면 위 보스 체력바만
- **화면 밖 구슬 길잡이**: 안 주운 보상 하트 구슬이 카메라 밖(48유닛 안)에 있으면 화면 가장자리에 분홍 하트 + 구슬 쪽 화살표 (가까운 3개까지, `SkillHUD.OrbGuide`)
- **HP 화면 경고등**: 체력 30% 이하에서 화면 가장자리가 붉게 맥동. 낮을수록 진하고 빠르게 (`SkillHUD.LowHealth`)
- 레벨 막대 + Tab 특성 창, 보스 체력바, 스테이지 이름 꼬리표·골드, 안내 문구
- **진행도(%) 없음** (2026-11-12 사람 결정): 스테이지 진행 막대·%를 없앴다. 방을 돌아다니며 탐험한다. 안에서 쓰는 기준은 **방 깊이** = 시작 방에서의 방 거리 ÷ 보스 방 거리(0~1, 화면에 안 보임): 배경 색조, 후반 곡(0.5), 중간보스 위치(주 경로 55%), 이중 스위치(0.5 근처), 전투·정예 문턱. 게임오버 창과 시작 화면 기록은 "시작 방에서 N칸"으로 적는다
- **일시정지**: Esc. 배경음악/효과음 볼륨, 계속하기 / 다시 시작(새 맵) / 시작 화면. 시간 정지·조작 잠금. 옆에 이번 런 요약(특성 단계, 고른 유물과 효과)
- **런 기록**: 게임오버·클리어 창에 레벨, 처치 수, 받은 피해, 돌파한 전투 구역, 연 봉인문 수, 고른 유물 (`RunStats`)
- **사망 연출** (애니메이션 대체): 1.2초 슬로모션(0.25배) → 회색으로 바래며 화면이 어두워짐 → 게임오버 창 뒤에 R/M 입력
- **화면 설정** (2026-11-12 플레이테스트 21번): 화면 비율 16:9 고정(레터박스), 16:9 해상도 선택, 창 / 테두리 없는 창 / 전체 화면. 시작 화면과 일시정지 메뉴에서 열고 PlayerPrefs에 저장.
- **시작 화면**: 개발자 모드 토글, 배경음악/효과음 볼륨, 최고 기록 (아래 저장 참고), 유물 도감 (C: 한 번이라도 고른 유물 격자, 게임 중에도 C로 열림(시간 정지), 마우스를 올리면 설명 한 줄, 상자 카드엔 처음 보는 유물에 NEW, 다 모은 판은 결과 창 금색 "유물 도감 완성!" + 시작 화면 ★)

### 저장 (구현됨: 기초)

- `SaveData`가 PlayerPrefs에 저장: 설정(개발자 모드, 배경음악/효과음 볼륨), 최고 기록(가장 빠른 클리어 시간, 최고 레벨 — 개발자 모드/일반 모드 따로).
- 클리어 창에 이번 기록과 최고 기록, 새 기록이면 "최고 기록!" 표시.
- **런 진행 저장** (`RunSave`): **2026-11-10 체크포인트 제거(사람 결정)로 지금은 저장하지 않는다.** 이유: 스테이지가 15분 안팎이고 하나뿐이라 "스테이지 시작 지점에서 이어하기"는 새 런과 다르지 않다. 아래 저장·이어하기 기능은 스테이지 2가 생기면 스테이지 전환 때 저장하는 용도로 코드에 남겼다(`RunSave.Version` 2로 옛 체크포인트 저장은 무시). 예전 동작: 레벨·특성·유물·체력·런 기록·청크 기록(쓰러뜨린 적 등)이 이어진다. 쓰러지거나 클리어하거나 새로 시작하면 지운다. 쓰러지기 전에 시작 화면으로 나갔다 이어 하면 체크포인트 상태로 돌아갈 수 있다(걸린 시간은 되감기지 않음, 막을지는 미정). A/B가 날린 마나 기록은 이어지지 않는다.

### 피격

- 플레이어/적 모두 피격 시 **경직**: 이동/점프/대쉬/공격 불가. 플레이어는 경직 동안 무적 (인내 특성으로 늘어남)
- 플레이어와 적의 몸체는 서로 밀어내지 않음. 접촉 데미지·공격은 겹침 판정
- 적끼리는 서로 피해를 주지 않음
- 실제 피해를 입으면 화면 흔들림
- 피격 이펙트: 실제 피해를 입으면 몸이 0.08초 하얗게 번쩍이고(`Resources/Shaders/SpriteFlash`) 작은 파편이 튄다 (`HitFlash`, 플레이어/적/보스 공통)
- 시각 효과 묶음 (`VfxPlayer`): 빨리 떨어지다 착지하면 발밑 먼지, 레벨업 때 플레이어를 따라가는 금빛 기둥, 적이 쓰러지면 별·하트 펑(보스·어미 슬라임 분열 제외), 유물 상자는 열기 전까지 반짝이고, 유물을 고르면 뚜껑이 튀어 올라 별로 터지며 gold 빛기둥·별·하트가 솟고 화면이 살짝 흔들린 뒤 상자 위에 유물 이름 띠가 2초쯤 떠 있다. 대쉬 잔상은 마법사 대쉬 프레임에 그려져 있다
- 피해 숫자: 굵은 글자 + 진한 테두리, 처음 0.1초 팝. 물리 피해 흰색·치명타 금색, 속성 피해는 속성색(치명타는 금색 테두리), 치명타는 1.5배 크기
- 경직 연출: 전용 애니메이션 대신 피격 순간 몸이 뒤로 14° 젖혀졌다가 경직 동안 돌아온다 (`HitStun`, 경직되지 않는 슬라임 킹은 제외). 적은 경직 동안 머리 위에서 색색의 별 3개가 빙글빙글 돈다 (`Systems/Effects/StunStars`, 최소 0.45초). 적마다 전용 경직 그림은 아직 없음

### 카메라 (구현됨)

- 플레이어를 부드럽게 추적, 스테이지 경계(전투 구역에 갇힌 동안은 구역 경계) 밖은 비추지 않음
- Rigidbody2D 보간으로 이동 중 번짐 방지

### 자원 시스템 (구현됨)

플레이어 기본값 (`StatTable`, 원본은 스탯 문서):

| 자원 | 기본값 | 규칙 |
| --- | --- | --- |
| 체력(HP) | 100 | 회복 구슬(전투 구역 보상·샘 곁방 30%, 생명 5 특성이면 45%), 중간보스 처치 50%, 특성으로 회복 |

| 마나(Mana) | 100 | A/B 공용. 스킬·평타에 소모, 자동 재생. 누가 쓰고 날렸는지 기록 |
| 골드(Gold) | 0 | **그 판 안에서만** (다음 판으로 안 넘어감). 몬스터가 떨어뜨린다 — 스테이지 1: 일반 50% 확률로 1~4, 정예 100% 10~20, 중간보스 100% 50~100(쌍둥이 기사 하나당 25~50), 최종보스 100% 100~200(분열한 슬라임 킹 하나당 50~100, 보스 소환 몹은 없음) (`Chunks/GoldDrops`). 쓰는 곳(식당·장비 상점)은 다음 작업 |

### 적 (구현 현황)

| 분류 | 적 | 특징 |
| --- | --- | --- |
| 쫄몹 | 슬라임 | 추적/왕복 순찰, 웅크렸다 도약 공격 |
| 쫄몹 | 고블린 / 고블린 병사 | 근접 |
| 쫄몹 | 고블린 궁수 | 거리 유지 + 화살 |
| 정예 | 어미 슬라임 | 쓰러지면 슬라임 3기로 분열 |
| 정예 | 고블린 대전사 | 광폭화 (`EnrageAbility`) |
| 보스 | 슬라임 킹 (스테이지 1) | 패턴 6개, 체력 50%에서 분열하며 2페이즈. 패턴은 README 참고 |
| 중간보스 | 쌍둥이 슬라임 기사 (스테이지 1, 보스까지 거리 55% 지점 방) | 불 기사 돌진 + 물 기사 방패(바람·땅 마법에 깨짐), 한쪽이 쓰러지면 남은 쪽 광폭화. 등장 때 위에서 떨어져 충격파와 함께 착지. README 참고 |

고블린 4종과 이펙트는 `Tools/ArtGen`으로 만든 임시 아트, 슬라임은 직접 만든 일러스트.

### 맵 생성: 청크식 스테이지 (구현됨)

- 스테이지 = 32×24 타일 청크를 가로로 이어 붙인 것. 청크 14종: 시작, 평지, 언덕, 낭떠러지, 가시밭, 절벽, 동굴, 무너지는 다리, 봉인문, 움직이는 발판, 전투, 정예 전투, 휴식(숨 고르기 평지, 체크포인트는 2026-11-10 제거), 보스.
- `StagePlanner`가 예상 시간 15분이 될 때까지 이동 구간 1~3개 + 전투 구역을 번갈아 놓는다. 진행도가 오를수록 어려워지고, 30% 지점에 정예 전투(55% 중간보스가 둘째 고비), 봉인문은 최대 1개, 마지막에 숨 고르기 + 보스.
- 지형 규칙은 점프 능력 기준(최대 2칸 오르기, 3칸 낭떠러지). `StageValidator`가 통과 가능 여부와 갇히는 구덩이를 검사하고, 실패하면 다시 만든다. EditMode 테스트로도 검증한다.
- `ChunkStreamer`가 플레이어 좌우 2청크만 씬에 만들고 멀어지면 치운다. 처치한 적, 돌파한 구역, 주운 보상, (체크포인트는 제거됨) 기록된다.
- 함정: 가시, 화염 분출구(화상), 화살 발사대, 무너지는 발판(플레이어나 적이 올라서면 무너지고, 위의 적도 떨어진다). 낭떠러지에 떨어지면 체력 15%를 잃고 마지막 안전 지점으로 복귀.
- **전투 구역**: 들어가면 양쪽 문이 닫히고 적이 차례로 나온다. 다 쓰러뜨리면 문이 열리고, 일반·정예 구역은 가운데에 회복 구슬(체력 30%, 마나 50%)을 떨어뜨린다.
- **봉인문 (스킬 퍼즐)**: 진행도 25~85%에 스테이지당 최대 2개. 길을 막은 마력 벽의 색·문양과 같은 속성(불/물/바람) 마법을 B가 맞혀야 열린다. 틀린 속성은 튕겨 나가며 벽이 하얗게 번쩍인다 (안내 문구는 2026-11-12 삭제). A와 B의 협력(A가 자리를 잡고 B가 맞는 영창을 치기)을 요구하는 첫 퍼즐. 마나는 재생되므로 실패해도 갇히지 않는다. 진행도 60% 이후의 봉인문은 문양이 둘이라 서로 다른 두 속성을 아래 문양부터 순서대로 맞혀야 한다 (하나를 맞히면 그 문양이 꺼지고 벽 색이 다음 속성으로 바뀜. 맞힌 개수는 청크를 다시 만들어도 유지). **협동 봉인문**: 진행도 25% 이후의 보물 곁방은 상자 앞을 문양 둘짜리 봉인문이 막는다. 아래 문양(방어막 거품 표시)은 A가 그 속성 방어막을 두른 채 문에 닿아야 풀리고(마법은 튕김), 위 문양은 B가 다른 속성 마법을 맞혀 푼다 (좌우 곁방 24열, 세로 곁방 8열·상자 4열 — `RoomShaper.HasPairGate`).
- **움직이는 발판 (컨트롤 퍼즐)**: 진행도 20% 이후. 점프로 못 건너는 낭떠러지를 발판이 오가며, 타이밍을 맞춰 올라타고 내린다. 떨어지면 낭떠러지 규칙(체력 15%, 복귀). 진행도 70% 이후에는 절반 확률로 갈아타기 변형(9칸 낭떠러지 둘 사이의 좁은 기둥에서 다음 발판으로 이어 탄다. 놓치면 기둥에서 한 바퀴 기다린다). 진행도 50% 이후 한 발판 낭떠러지의 절반은 마법 스위치 발판(멈춘 동안 밟을 수 없는 흐릿한 잠든 발판, 건너편 룬에 같은 속성 B 마법을 맞히면 10초 동안 오간다 — A가 건너려면 B의 마법이 필요한 협동 퍼즐). 안내 문구 없이 룬 모양(숨 쉬는 문양, 룬을 가리키는 빛 화살 무늬, 맞으면 빛 고리)으로 알린다. 스위치 낭떠러지(9~10칸)에는 마력 안개가 깔려 순간이동·대시가 흩어지므로(안개 근처 공중에서도 금지) 발판을 타야만 건넌다 (2026-11-12 플레이테스트 피드백). 이중 스위치(발판마다 다른 속성 룬, 둘째 룬은 기둥 위에서 쏜다)는 판마다 꼭 하나, 진행도 50% 뒤 첫 이동 방에 나온다 (2026-11-12, 예전에는 80% 이후 무작위라 거의 안 나옴). 80% 이후 갈아타기의 절반도 이중 스위치.
- **휴식 청크**: 숨 고르기 평지 (전투 방이 연달아 오지 않게 하는 완충). 체크포인트 제단(체력 50%·마나 회복·런 저장)은 2026-11-10 사람 결정으로 제거 — 코드는 `Trash/`. 낙하 복귀는 `FallRecovery`가 밟은 땅을 스스로 기록한다.
- **유물 상자** (정예 전투 보상): 회복 구슬 옆에 나온다. 유물 29종 (2026-11-12 종이비행기: 순간이동 마나 -25%, 복주머니: 몬스터 골드 +50%, 단골 도장: 마을에서 사는 값 -20%, 돼지 저금통: 마을에 처음 들어가면 가진 골드의 25% 이자, 최대 50) 중 3개(네잎 클로버가 있으면 4개)를 보여 주고 A/B가 함께 하나를 고른다 (게임 정지). 효과는 특성 약 4포인트 분량의 능력치 7종과 특수 효과 18종(낙하 피해 감소, 처치 시 회복, 날린 마나 환급, 대쉬 뒤 0.5초 무적, 마나 부족 시 체력으로 대신 내기 40초 1회, 쓰러짐 1회 버티기 등, B의 공격 마법 발동 시 마나 +4 응원 리본, 처치 시 15% 확률로 적 자리에서 금별이 날아와 닿을 때 마나 +6 별똥 조각·용사의 훈장, 레벨업마다 체력 +10 도토리 주머니, 보상 구슬 회복 +15%p 꿀단지, 무너지는 발판이 0.9초 버티는 젤리 방석, 별사탕, 보상 구슬을 4칸 밖에서도 끌어오는 말굽 자석)이고 런이 끝나면 사라진다. 누가 원하는 유물(A/B/공용)을 고를지도 탓할 거리. 유물을 고르면 상자 옆에 **장비** 하나가 떨어진다(중간보스 상자는 수식어 한 등급 위).
- **장비** (2026-11-12, 설계 [EquipmentDesign.md](EquipmentDesign.md)): A/B 공용 한 벌 — 로브(방어)·지팡이(공격)·신발(이동) 각 4종, 수식어 6등급(부서진·낡은·보통·튼튼한·빛나는·전설의)이 능력치와 가격에 배율을 곱한다. 바닥 장비에 닿으면 비교 카드(지금 ↔ 새 장비, 차이 초록/빨강)에서 1 바꿔 끼기 / 2 두고 가기, 바꿔 끼면 옛 장비가 그 자리에 남는다. 일시정지 요약에 장비 3칸, 결과 창 유물 줄 오른쪽에 마지막 장비 3칸 아이콘. 판이 끝나면 사라진다. 마을(식당·장비 상점)은 방 격자의 막다른 곁방 하나 — 꾸미기·NPC·마을 곡은 README 참고. 메타 진행 초안: [MetaProgressionDraft.md](MetaProgressionDraft.md)
- **보스 청크**: 보스를 쓰러뜨리면 출구가 열리고, 들어가면 스테이지 클리어.
- 이전의 방(Room) 격자 구조는 청크식으로 대체되었다.

## 6. 기술 메모

- 오브젝트 구성은 `PlayerSpawner.Build` / 적별 Spawner(예: `SlimeSpawner.Build`)가 단일 출처이며, 에디터 툴이 프리팹으로 굽는다. 자세한 내용은 [README.md](../README.md) 참고.
- 청크 생성기(`Systems/MapGeneration/Chunks`)는 UnityEngine 없는 별도 어셈블리(`IBlameYou.StageGeneration`)라 EditMode 테스트와 `Tools/StageGen`에서 Unity 없이 검증한다.
- 아트 에셋(2D Platformer Tileset)은 저장소에 포함하지 않는다(`.gitignore`). 임시 아트/사운드는 `Tools/ArtGen`, `Tools/AudioGen`으로 생성.
