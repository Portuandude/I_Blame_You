## 2. 게임 시스템 디자인

### 게임 진행 방식

- 로그라이크
  - 스토리형 (로직, 퍼즐)
  - 패턴 파훼형 (EX. 컵헤드, 다크소울류)
- 플랫포머 횡스크롤 or 탑다운 → **현재 프로토타입은 횡스크롤 2D 플랫포머로 구현 중**
- 슈팅 액션
- 쫄몹 + 정예몹 + 중간보스 + 챕터보스 + 맵퍼즐 (컨트롤 퍼즐, 스킬 퍼즐)
- 맵 — 챕터별로 n개의 방, n+@의 맵을 랜덤으로, 외선형 진행
  - 레벨 디자인(플랫폼 배치 등)은 추후 직접 진행 예정이라, 현재 자동 배치 플랫폼은 꺼둔 상태

### 게임 인터페이스 (UI/UX)

- HP (화면 경고등)
- 상태이상 바 (캐릭터 대가리 위)

**현재 구현된 UI**: 캐릭터 머리 위 상태 바 (`StatusBarsUI`)

- HP 바: 캐릭터 상단에 고정
- 마나 바 / 기력 바: HP 바 아래에 각각 HP 바 높이의 1/5 크기로 표시
- 각 시스템의 변경 이벤트를 구독해 잔량을 실시간 반영

**미구현**: HP 화면 경고등, 상태이상 바

### 플레이어 조작 / 능력 (구현됨)

| 입력 | 동작 | 비고 |
| --- | --- | --- |
| A/D, ←/→ | 이동 | |
| Space | 점프 | 지면에서만 |
| Shift + 이동 | 달리기 | 기력 초당 25 소모, 기력 10 이상이어야 재시작 |
| Left Ctrl | 대쉬 | 기력 50 소모, 0.2초간 수평 돌진, **대쉬 중 피격 무적** |
| 마우스 좌클릭 | 공격 | 전방 판정 박스, 데미지 10, 대쉬 중 불가 |

### 피격 (구현됨)

- 플레이어/적 모두 피격 시 **경직**: 경직 동안 이동/점프/대쉬/공격 불가 (플레이어 0.4초, 슬라임 0.3초)
- 플레이어는 **경직 동안 무적** (연속 피격 방지)
- 플레이어와 적의 **몸체끼리는 서로 밀어내지 않음** (몸체 충돌 비활성). 접촉 데미지·공격은 겹침 판정으로 처리
- 적끼리는 서로 피해를 주지 않음
- 경직 전용 애니메이션/피격 이펙트는 미구현

### 자원 시스템 (구현됨)

| 자원 | 기본값 | 규칙 |
| --- | --- | --- |
| 체력(HP) | 100 | 데미지/회복, 무적 플래그(대쉬 등에서 사용) |
| 기력(Stamina) | 100 | 달리기·대쉬에 소모, 소모 후 잠시 뒤 자동 재생 |
| 마나(Mana) | 100 | 초당 5 자동 재생. **소모하는 스킬은 아직 없음** |

### 적 (구현 현황)

| 분류 | 상태 | 내용 |
| --- | --- | --- |
| 쫄몹 | 프로토타입 | 슬라임: 벽에 부딪힐 때까지 좌우 왕복, 접촉 시 데미지 8(1초 쿨다운), HP 30, 사망 애니메이션 후 제거 |
| 정예몹 | 미구현 | |
| 중간보스 | 미구현 | |
| 챕터보스 | 미구현 | |
| 맵퍼즐 | 미구현 | 컨트롤 퍼즐, 스킬 퍼즐 |

### 맵 생성 (구현 현황)

- 챕터 맵: 메인 경로(n개) + 곁가지 방(n+@)을 랜덤 워크로 격자에 배치 (`RoomGenerator`)
- 방 타입: Start / Normal / Elite / MiniBoss / ChapterBoss / Puzzle (타입별 색으로 시각화)
- 현재는 **시작 방 하나만** 실제 지오메트리(바닥/좌우 벽)와 함께 생성되고 나머지 방은 배경 색으로만 표시됨. 방 사이 이동(문/통로)은 미구현
- 방 크기 64×36 유닛
