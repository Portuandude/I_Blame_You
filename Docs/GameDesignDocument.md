## 2. 게임 시스템 디자인

### 게임 진행 방식

- 로그라이크
  - 스토리형 (로직, 퍼즐)
  - 패턴 파훼형 (EX. 컵헤드, 다크소울류)
- 플랫포머 횡스크롤 or 탑다운
- 슈팅 액션
- 쫄몹 + 정예몹 + 중간보스 + 챕터보스 + 맵퍼즐 (컨트롤 퍼즐, 스킬 퍼즐)
- 맵 — 챕터별로 n개의 방, n+@의 맵을 랜덤으로, 외선형 진행

### 게임 인터페이스 (UI/UX)

- HP (화면 경고등)
- 상태이상 바 (캐릭터 대가리 위)
