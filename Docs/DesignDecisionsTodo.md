## B. 스토리·연출

### B0. ⭐ 숨은 능력치 "선악도"·"인과율" (2026-11-24 사람 결정: 추가한다)

플레이어 캐릭터에게 **화면에 보이지 않는** 능력치 두 개를 넣는다.

✅ **정함 (2026-11-24 사람)**
- **선악도**: 맵 곳곳에 **NPC와 NPC의 서사**를 넣는다. NPC는 **악인·중립·선인** 세 부류이고, 이들과 어떻게 얽히는지가 선악도를 바꾼다.
- **인과율**: **얼마나 많이 부활했는지**(쓰러져 도시에서 다시 깨어난 횟수)로 정해지고 **엔딩 분기점**에 영향을 준다.

남은 것 (기획서 쓰기 전에 정하면 좋은 것)
1. ✅ **NPC가 어디에 나오나**: 새 방 종류 "NPC 방" (C5, 정함 2026-11-24). 기존 방에도 섞일지는 아직
2. ✅ **선택 방식 (정함 2026-11-24)**: A와 B에게 **똑같은 선택지**를 준다. 둘이 같은 것을 고르면 그대로, **다르면 룰렛**으로 실제 행동을 정한다. 선악도는 **각자 고른 것**대로 오른다 (예: A 선·B 악 → 룰렛이 행동을 정하고, A는 선 성향 +, B는 악 성향 +). 즉 선악도는 **아루·벨 각자** 갖는다.
   - 남은 것: 룰렛 확률(50:50 / 선악도·인과율로 기울임), 고르는 동안 서로의 선택을 숨길지(추천: 동시에 몰래 — 온라인에선 각자 화면), 제한 시간, 룰렛 결과에 따라 선악도가 더 오르는지(예: 룰렛에서 이긴 쪽 +보너스)
3. ✅ **NPC 서사는 판을 넘어 이어진다 (정함 2026-11-24)**: 같은 NPC를 여러 판에 걸쳐 다시 만나 이야기가 진행된다. 단 **NPC는 부활하지 못한다** — 플레이어의 선택으로 죽거나 영구적인 영향을 받으면 다음 판에도 그대로 남는다.
   - 남은 것: 세계 상태를 되돌리는 방법(새 게임·저장 슬롯 여러 개, 추천: 저장 슬롯 3개), NPC가 죽으면 그 서사와 연결된 엔딩·보상이 닫히는지, 한 판에서 만나는 NPC 수, 스테이지 5개에 NPC 몇 명(가안: 스테이지마다 악인·중립·선인 1명씩 = 15명)
4. ✅ **선악도가 바꾸는 것 (정함 2026-11-24)**: 엔딩 + **NPC 반응** — 대사, 허가(들여보내 줌/거절), 요청(부탁·퀘스트), 가격(인상·할인) 등.
   - 남은 것: 선악도가 A·B 각자인데 몸은 하나라, NPC가 **누구의 선악도**를 보는지 — 가. 두 값의 합 · 나. NPC와 성향이 더 가까운 쪽 · 다. A·B에게 따로 반응(대사를 각자에게, 추천: "누구 탓" 갈등이 살아남)
5. ✅ 선악도는 아루·벨 각자 (위 2번). 인과율(부활 횟수)은 한 몸이라 공용
6. ✅ **인과율 방향 (정함 2026-11-24)**: 개발자 모드 부활은 **세지 않는다**. **부활이 적을수록 좋은 엔딩**. 부활이 많아질수록 **분위기가 어두워지고**, 아루·벨의 대사에도 부정적인 영향이 드러난다.
   - 남은 것: 부활 횟수를 인과율 0~100으로 바꾸는 식(예: 부활 1번 = +N, 구간은 0~25 낮음 · 25~75 보통 · 75+ 높음, B1 참고), 로그라이크라 초보는 많이 쓰러지는데 처음 하는 사람이 너무 빨리 나쁜 엔딩으로 몰리지 않게 할지(예: 스테이지 1에서의 부활은 덜 셈), 어두워지는 범위(대사만 / 배경 색·음악까지), 기능 테스트 모드 부활도 빼는지(추천: 뺌)
7. ✅ **숨김 (정함 2026-11-24)**: 숫자도 따로 주는 힌트도 **없다**. 드러나는 것은 게임 안 결과뿐 (인과율 → 분위기·대사, 선악도 → NPC 반응·엔딩).

✅ **정함 (2026-11-24 사람)**

- **영혼석 모양은 담긴 양에 따라 색이 다르다**: 흰색 → 파란색 → 붉은색 → 황금색 (메이플스토리 메소가 동전 → 꾸러미 → 지폐 다발로 바뀌는 방식 참고, 그림은 이 게임 것으로).

- **떨어지는 자리**: 영혼석은 죽은 적의 **머리 쪽**, 골드는 **바닥**.
- **줍는 소리**: 여러 개를 한꺼번에 주워 소리가 겹치면, 겹친 수에 비례해 하나하나의 소리를 줄여 전체가 너무 커지지 않게.
- 남은 것: 영혼석 색 구간(가안: 흰 1 · 파랑 5 · 빨강 10 · 황금 50), 골드가 많이 나올 때(정예·보물 고블린) 10·50골드 같은 더 큰 단위를 둘지
