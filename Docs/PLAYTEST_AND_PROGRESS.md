# 테스트 방법과 진행도

> 2026-11-11 정리. 기준: `develop` (PR #33 머지 직후, 커밋 `d8ed839`).
> 결정된 방향과 아직 정해야 할 것은 [DIRECTION_AND_DECISIONS.md](DIRECTION_AND_DECISIONS.md)에 따로 있다.

## 1. 최신 코드 받기

1. GitHub Desktop(또는 git)에서 `Desktop/I_BLAME_YOU` 저장소를 열고 브랜치를 **develop**으로 둔다.
2. **Fetch origin → Pull origin**. (명령줄이면 `git checkout develop && git pull origin develop`)
3. 자동 개발이 돌고 있는 중이어도 develop은 PR이 머지될 때만 바뀌니 언제 받아도 된다.

## 2. Unity에서 열기

1. Unity Hub에서 프로젝트를 연다. 버전은 **Unity 6000.3.24f1**.
2. 처음이거나 `Assets/2D Platformer Tileset/`가 없으면 에셋 팩을 임포트한다 (저장소에는 없음).
3. 메뉴 **Tools > I Blame You > Generate Sprites And Animations**를 한 번 실행한다.
   컴포넌트 구성이 바뀐 PR을 받은 뒤에는 다시 실행해야 프리팹이 갱신된다. 오래간만에 받았다면 그냥 한 번 돌리는 게 안전하다.
4. `Assets/Scenes/testScene.unity`를 열고 **Play**. 시작 화면이 뜬다.
5. Project Settings > Player > Active Input Handling이 **Both**인지 확인한다 (New 단독이면 입력이 안 먹는다).

콘솔에 빨간 컴파일 오류가 있으면 플레이 전에 그 메시지를 그대로 알려 주면 된다.

## 3. 자동 테스트 (EditMode)

| 방법 | 하는 법 | 언제 |
| --- | --- | --- |
| GitHub CI | PR마다 `editmode` 잡이 Unity로 컴파일 + EditMode 테스트를 돌린다. develop 보호 규칙이라 초록이어야 머지된다 | 따로 할 일 없음. PR 화면의 체크만 보면 된다 |
| Unity 안에서 | **Window > General > Test Runner > EditMode → Run All** | 직접 코드를 고쳤을 때 |
| Unity 없이 | `bash Tools/Dev/run_editmode_tests.sh` (mono + NUnit, 리눅스/WSL) | 자동 개발 세션이 푸시 전에 쓴다. 지금 100개 |

자동 테스트가 보는 것은 스테이지/방 생성, 피해 공식, 유물, 순간이동 규칙, 도감 같은 **순수 로직**뿐이다.
그림·소리·UI 배치·조작감은 아래 플레이테스트로만 확인된다.

## 4. 플레이테스트 체크리스트

자동 개발 PR #21~#33에서 "사람이 직접 봐야 한다"고 남긴 것들을 모았다. 한 판(약 15분)씩 돌면서 보면 된다.
이상한 점은 **항목 번호 + 무엇이 어땠는지** 한 줄씩만 적어 주면 백로그로 옮긴다.

시작 화면의 **개발자 모드**(기본 켜짐)는 한 사람이 A/B를 같이 조작한다. F1 무적, F2 마나 무한, F3 주변 적 처치, F4 회복으로 빨리 넘어갈 수 있다.
15분 길이 확인(5번)만은 개발자 치트 없이 해야 정확하다.

### 4-9. 그림 파일 .meta 확인 (사람만 가능)

- [ ] 31. `Assets/Resources/Effects/` 아래 옛 PNG 132개(Cast, Flight, Hit, Dust, DeathPop, LevelUp, Sparkle)는 저장소에 `.meta`가 없다.
  Unity를 열면 PC에서 자동으로 만들어지는데, 이때 기본 설정(2의 거듭제곱 크기로 줄이기 등) 때문에 **레벨업 빛기둥(120×240) 같은 이펙트가 찌그러져 보일 수 있다**.

  - 찌그러졌다면: 알려 주면 클라우드에서 `.meta`를 만들어 올린다. 다만 **PC에 이미 생긴 `.meta`와 GUID가 달라 충돌**할 수 있어서, 그 경우 PC에 생긴 `.meta`를 GitHub Desktop으로 커밋해 올리는 쪽이 안전하다 (어느 쪽으로 할지 [결정 문서 2-6](DIRECTION_AND_DECISIONS.md#2-6-옛-이펙트-png-meta-처리) 참고)
