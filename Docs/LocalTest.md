# 내 PC에서 최신 버전 테스트하기

개발을 다시 시작하기 전에, 내 컴퓨터(바탕화면 `I_BLAME_YOU` 폴더)에서 최신 게임을 받아 해 보는 순서. (2026-11-24)

## 1. 최신 파일 받기 (GitHub Desktop)

1. GitHub Desktop을 열고 왼쪽 위 **Current repository**가 `I_Blame_You`인지 본다.
2. 가운데 위 **Current branch**가 `develop`인지 본다. 아니면 눌러서 `develop`을 고른다.
3. 오른쪽 위 **Fetch origin**을 누른다. 버튼이 **Pull origin**으로 바뀌면 한 번 더 누른다.
   - 왼쪽 **Changes** 탭에 `.meta` 파일이 수백 개 보여도 괜찮다. Unity가 열 때 스스로 고친 설정 파일이다. 커밋하지 말고 그대로 둔다.
   - Pull이 "충돌" 같은 말로 멈추면 그대로 두고 Claude에게 말한다 (대신 맞춰 줄 수 있다).

## 2. Unity에서 열고 준비하기

1. Unity Hub에서 `I_BLAME_YOU` 프로젝트를 연다. 처음 몇 분은 불러오기 막대가 돈다.
2. 위 메뉴 **Tools > I Blame You > Generate Sprites And Animations**를 누른다 (몬스터·플레이어 그림과 프리팹을 새 코드에 맞게 다시 만든다).
3. 이어서 **Tools > I Blame You > Generate Prefabs**도 한 번 누른다.
4. 아래 **Console** 창(없으면 Window > General > Console)에 빨간 오류가 없으면 준비 끝.

> 새 버전을 받을 때마다 1 → 2를 다시 한다.

## 3. 에디터에서 해 보기 (가장 빠름)

1. Project 창에서 `Assets/Scenes/testScene`을 두 번 눌러 연다.
2. 위 가운데 ▶ (Play)를 누른다. 시작 화면이 뜬다.
3. 시작 화면에서 고른다.
   - **개발자 모드** (기본 켜짐): 혼자서 A(이동)와 B(공격)를 다 조작. 미니게임 대신 숫자키로 바로 마법.
   - **플레이 테스트 시작**: 스토리 → 도시 메뉴 → 출발로 진짜 판. (스토리는 Space + 마우스 왼쪽을 같이 0.8초 누르면 건너뜀)
   - **기능 테스트 시작**: 적 없는 시험 맵. F7/F8로 몬스터·이벤트 부르기, F9 유물, F12 장비.
4. 개발자 모드 치트: F1 무적, F2 마나 무한, F3 주변 적 처치, F4 체력 회복.
5. 다시 ▶를 누르면 멈춘다.

## 4. 게임 파일(.exe)로 해 보기

에디터 없이, 실제 게임처럼 창으로 해 볼 때.

1. **Tools > I Blame You > Windows 빌드 만들기**를 누른다 (몇 분 걸림).
2. 끝나면 탐색기가 `I_BLAME_YOU\Builds\Windows\` 폴더를 열어 준다. `IBlameYou.exe`를 두 번 누르면 실행.
3. 친구와 컴퓨터 두 대로 할 때: `Builds\Windows` 폴더를 통째로 압축해서 친구에게 보내고, 시작 화면 **온라인 2인**에서 호스트/참가 (자세한 건 [OnlinePlay.md](OnlinePlay.md)).

## 5. 이번에 바뀐 것 확인 (방 이동 페이드, PR #139)

- 방 문(옆 끝, 천장·바닥 구멍)을 지나면 화면이 0.16초 동안 까맣게 되고, 옆 방으로 옮긴 뒤 0.3초쯤 걸려 밝아진다.
- 까매지는 동안 캐릭터는 문 앞에 멈춰 있고 맞지 않는다.
- 온라인 2인이면 친구 화면도 같이 까매졌다 밝아져야 한다.
- 너무 길거나 짧게 느껴지면 숫자만 말해 주면 바꾼다.

## 6. 문제가 생기면

- Console의 빨간 오류 줄을 눌러 아래 내용을 복사하거나 화면을 찍어서 보낸다.
- "예전에 고친 버그가 그대로다" 싶으면 1번(최신 받기)과 2번(Generate)을 했는지 먼저 본다. 예전 버전 그대로인 경우가 가장 많다.
